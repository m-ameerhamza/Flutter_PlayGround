## Overview
**WalletApp** is a modern financial management tool designed with a clean, intuitive interface. Built using **Flutter** and **Dart**, and backed by **Firebase**, it provides a secure and real-time experience for managing personal finances.

## Key Features
* **Real-time Dashboard:** Overview, income, and expenses.
* **Card Management:** Support for multiple virtual cards with status indicators.
* **Quick Operations:** Instant buttons for Sending, Topping Up, and Transfers.
* **Expense Analytics:** Visualized weekly spending charts.
* **Cloud Persistence:** Real-time data sync via Cloud Firestore.

## Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Authentication, Firestore)
- **State Management:** Provider / Riverpod
- APIs
- Databases (Use PostgreSQL for Fast & Efficient Outcome)

## Installation
1. Clone the repository Or Download the lib folder from here: `git clone https://github.com/your-username/wallet-app.git`
2. Create a default flutter project
3. Delete your existing 'lib' folder and paste this 'lib' folder 👆.
4. Replace your 'pubspec.yaml' with above 'pubspec.yaml'.
5. Run flutter pub get
6. Run flutter run
7. READY!
